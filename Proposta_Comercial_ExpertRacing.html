01

API do Mercado Livre —
respostas automáticas.

Confirmação técnica antes de falar de preço.

// veredicto

A API permite responder perguntas automaticamente via POST /answers.

Pesquisa realizada diretamente na documentação oficial developers.mercadolivre.com.br. O endpoint existe, está ativo e é usado por milhares de integrações no Brasil.

// endpoint · responder pergunta

POST https://api.mercadolibre.com/answers

// Headers
Authorization: Bearer {ACCESS_TOKEN}
Content-Type: application/json

// Body
{
  "question_id": 3957150025,
  "text": "Olá! Este produto é bivolt (110V/220V). Temos em estoque..."
}

// Resposta 200 OK
{ "id": 987654321, "status": "ACTIVE", "date_created": "2026-06-18T10:30:00..." }

// como o bot recebe perguntas em tempo real

1
Comprador faz pergunta no anúncio → ML dispara webhook imediato para o servidor do bot
2
Payload recebido: { "resource": "/questions/5036111111", "topic": "questions" }
3
Bot faz GET /questions/{id} para buscar o texto completo + dados do produto
4
IA (Groq Llama 3.3 70B) gera resposta contextualizada com histórico e descrição do produto
5
Bot posta via POST /answers → comprador recebe em menos de 2 segundos

Ponto de atenção: O ML recomenda fluxo semiautomático (bot sugere → humano aprova). Respostas detectadas como template fixo podem ser moderadas. A solução: usar IA com contexto real de cada produto — cada resposta fica única, natural e passa pelo filtro.
